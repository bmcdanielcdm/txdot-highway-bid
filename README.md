# TxDOT Highway Bid Program

Planning workbook for a TxDOT highway letting. Official bids are submitted in iCX, not from this file.

## Live page

After GitHub Pages is turned on, the site is:

https://bmcdanielcdm.github.io/txdot-highway-bid/

Settings → Pages → Build and deployment → Deploy from branch → `main` / root → Save.

## Workbook

`TxDOT_Highway_Bid_Program.xlsx` is the bid program. Upload it to this repo (Add file → Upload files) so the download button on the live page works. The GitHub API used to create this repo only accepts text files, so the spreadsheet has to be uploaded from your computer.

## Import a Whitley & Siddons job

1. In EasyLinkPro, export the bid-item list to Excel.
2. Open the WS Import sheet.
3. Paste the job header (CSJ, highway, county, district, letting date, engineer's estimate).
4. Paste items under row 15: bid code, description, unit, quantity.

Codes may be `500-7001`, `500 7001`, or `5007001`.
